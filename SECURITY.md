# Security

This project is a game demo.
It runs locally and does not collect data.

## Report a problem

If you find a security problem, open an issue.
Use the issue tracker on this repository.
Include the Godot version and the steps to reproduce.
Do not share secrets in the report.

## Fix policy

We fix confirmed problems in a normal release.
We do not run a paid bug bounty program.
We do not have a private disclosure channel.
